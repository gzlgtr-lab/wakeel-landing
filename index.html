كيف يعمل

مسار واحد من المعرفة إلى الإجراء.

01

اربط المعرفة

هيّئ سياساتك ومقالاتك ومصادرك عبر موصلات آمنة. حالة الفهرسة تبقى ظاهرة.

02

افهم السياق

صمّم اللغة والنبرة وقواعد الثقة والقنوات بما يناسب سوقك.

03

وجّه القرار

أظهر المصدر والسبب والمسار المقترح بدل صندوق أسود يصعب مراجعته.

04

صعّد بمسؤولية

ينتقل الطلب الحساس إلى إنسان مع ملخص وسياق، ولا يرسل النظام ردًا آليًا خفيًا.

الحوكمة والثقة

وضوح أكبر قبل أي ادعاء أمني.

Wakeel في هذا المستودع واجهة ثابتة جاهزة للربط؛ لا توجد هنا قاعدة بيانات أو جلسات حقيقية أو اعتماد امتثال.

RBAC

صلاحيات قابلة للتوسعة

واجهة مهيأة لأدوار المالك والمدير والمشرف والمحلل، على أن تُفرض الصلاحيات في الخادم عند بناء المنتج.

LOG

تدقيق قابل للتتبع

صمّم الأحداث الحساسة حول سجل تدقيق، وحافظ على الأسرار في الخادم لا في التخزين المحلي أو الواجهة.

SAFE

لا نستخدم شعارات عملاء أو شهادات أو نسب دقة غير موثقة. كل أرقام العرض موسومة بأنها توضيحية.

الأسئلة الشائعة

إجابات صريحة قبل البداية.

هل هذه نسخة SaaS متصلة بالإنتاج؟

لا. هذه واجهة ثابتة محسّنة وعرض محلي. لا تحتوي على تسجيل دخول أو قاعدة بيانات أو دفع حقيقي. توفر البنية الحالية أساسًا بصريًا وتفاعليًا صادقًا للربط لاحقًا.

هل تحفظون الرسائل أو التسجيلات الصوتية؟

لا يحفظ العرض الرسائل، ولا يبدأ الميكروفون تلقائيًا. تشغيل الصوت اختياري عبر Web Speech API عندما يدعمه المتصفح.

كيف يتم حجز العرض؟

النموذج يرسل JSON إلى Formspree عند توفر الشبكة. عند فشل الطلب تظهر رسالة قابلة لإعادة المحاولة ولا يحدث تحويل تلقائي.

هل Wakeel حاصل على شهادات امتثال؟

لا يوجد في المستودع دليل على شهادات. يجب مراجعة أي ادعاء قانوني أو أمني من المالك قبل النشر.
